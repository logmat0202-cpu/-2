# Кубы разлома

Браузерная 3D-головоломка на Three.js: 10 основных уровней, 6 механик, отдельное обучение, подсказки, отмена, сохранение прогресса и финал. Работает с клавиатурой и мышью и с сенсорным экраном. Графика и звук создаются программно, шрифты включены в проект, платные API не нужны.

**Как открыть игру для всех:** [пошаговая инструкция](docs/PUBLICATION.md). GitHub Pages workflow уже находится в `.github/workflows/pages.yml`. Пути ресурсов относительные: проект можно разместить в корне сайта или в подпапке с любым названием.

## Запуск

Нужен Node.js 20.19+ или 22.12+ и современный браузер с WebGL.

```sh
npm ci
npm run dev
```

Откройте адрес Vite, обычно http://localhost:5173.

```sh
npm test
npm run build
npm run preview
```

Для хостинга используется содержимое `dist`. Исходный `index.html` нельзя просто открыть как `file://` и получить работающую сборку.

## На телефоне

- **Левый джойстик** — движение относительно камеры. Небольшое отклонение даёт медленный шаг.
- **Свайп по свободной части 3D-сцены** — обзор. Два пальца на сцене — приближение/отдаление.
- **Прыжок** — прыгнуть. **Взять / Отпустить** — взаимодействовать с ближайшим кубом.
- С захваченным кубом двигайте джойстик: короткое отклонение перемещает на клетку. Удержание продолжает движение. Отпускание куба во время шага завершает этот шаг.
- **Поворот** появляется при захвате отражателя.
- На островах с эхо доступны **Запись**, **Повтор** и **Сброс**. Повтор начинается с исходной точки, ждёт 5 секунд в конце и запускает следующий цикл.
- **↶** — отмена, **↺** — перезапуск с подтверждением, **✦** — три этапа подсказки, кнопка в правом верхнем углу — пауза.

Можно одновременно двигаться, вращать камеру и прыгать. Смена ориентации и прерывание касания сбрасывают ввод; уход из вкладки ставит игру на паузу. Меню и управление работают вертикально и горизонтально. Поддерживается безопасная зона вырезов экрана.

В паузе есть настройки чувствительности, громкости и графики. **Авто** ограничивает разрешение и тени для телефона, при устойчиво низкой частоте кадров снижает качество. **Экономно** отключает динамические тени и уменьшает разрешение. Кнопка полного экрана появляется только при поддержке браузером; на iPhone она может быть недоступна.

## На компьютере

- **WASD** — движение относительно камеры.
- **Мышь** — вращение камеры; **колесо** — расстояние.
- **Пробел** — прыжок.
- **E** — захватить / отпустить куб, **Q** — повернуть отражатель.
- **V / B / C** — начать или закончить запись / повтор / сброс эхо.
- **Z** — отмена, **R** — заново, **H** — подсказка, **Esc** — пауза.

Для захвата курсора используйте HTTPS или localhost. При запрете Pointer Lock можно удерживать правую кнопку мыши для обзора.

## Прогресс

localStorage (`rift-cubes-v1`) хранит открытые острова, текущий уровень, громкость, чувствительность и выбранное качество графики. Сохранения прежней версии совместимы. Они остаются на конкретном устройстве и домене; перенос на новый хостинг не переносит их автоматически.

## Структура

- `src/levels.js` — 10 планировок, обучение, цели, подсказки, решения.
- `src/model.js` — механики, перемещение кубов, запись эхо и отмена.
- `src/player.js` — движение, прыжки, физика, захват и камера.
- `src/touch.js` — мультитач, аналоговый джойстик, свайпы, pinch и сброс ввода.
- `src/world.js` — процедурная сцена, тени, анимации, пакетная отрисовка плит и качество графики.
- `src/main.js` — игровой цикл, меню, подсказки, сохранение и завершение.
- `src/audio.js` — синтезированный атмосферный фон и звуки.
- `.github/workflows/pages.yml` — сборка, тесты и публикация через GitHub Pages.

## Проверки

`npm test` запускает 37 проверок решений, маршрутов, физики и аналогового ввода. Проверяются все 10 уровней и обучение, коллизии и остановка связанной пары, прыжки на уступы, подъёмник, камера, фазы, лучи, энергия, эхо, отмена и доступность каждого перемещения решения.

Браузерные сценарии:

```sh
node tests/browser-qa.cjs
node tests/mobile-qa.cjs
```

Для них нужны локально запущенный `npm run dev`, Playwright и Chromium. При необходимости задайте `PLAYWRIGHT_MODULE` и `CHROMIUM_PATH`. Мобильные сценарии используют настоящие мультитач-события браузера, а не вызовы обработчиков кнопок напрямую. Проверяются одновременные джойстик/камера/прыжок, pinch, захват и отмена, поворот, запись эхо, подсказки, пауза, смена ориентации и экраны 320–844 CSS-пикселя.

QA-хуки включены только при запуске сервера разработки с `?qa` и удаляются из production-сборки. Проверка в эмуляции не заменяет тест на физическом телефоне; производительность зависит от устройства и браузера. Темп 2–5 минут на остров — ориентир дизайна, а не результат пользовательского исследования.
