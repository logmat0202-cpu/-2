# Как сделать «Кубы разлома» общедоступными

Игра — обычный статический сайт: Three.js, HTML, CSS и JavaScript. Сервер, база данных, ключи OpenAI и платные API не нужны. Все шрифты включены. Прогресс хранится в браузере посетителя.

Варианты ниже независимы: выберите один. Для переноса на GitHub рекомендуется вариант 1. Если нужна только быстрая публичная ссылка — вариант 2.

Если репозиторий с прежней версией уже существует, сначала используйте [обновление до 30 уровней](UPDATE-30.md).

## 1. GitHub Pages: исходники и автоматическая публикация

В проект уже включены `vite.config.js` с относительными адресами ресурсов и `.github/workflows/pages.yml` со сборкой и публикацией. Название репозитория может быть любым: менять пути не нужно.

### Через интерфейс GitHub

1. Скачайте и распакуйте **архив исходников версии на 30 островов**.
2. На GitHub создайте новый репозиторий, например `rift-cubes`. Выберите **Public**. Это позволяет использовать GitHub Pages на бесплатном личном плане. Можно создать репозиторий сразу с README, чтобы появился раздел Settings.
3. Откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
4. Откройте вкладку **Code → Add file → Upload files**. Загрузите **содержимое** папки проекта в корень репозитория. Рядом должны лежать `package.json`, `package-lock.json`, `index.html`, `vite.config.js` и папки `src`, `public`, `tests`, `.github`. Не загружайте один ZIP вместо распакованных файлов и не вкладывайте проект в дополнительную папку.
5. Убедитесь, что файл **`.github/workflows/pages.yml`** действительно появился в репозитории: системы иногда скрывают папки, начинающиеся с точки. Если он не загрузился, нажмите **Add file → Create new file**, укажите имя `.github/workflows/pages.yml` и вставьте содержимое одноимённого файла из архива.
6. Сохраните файлы в ветку **main**. Нажмите **Commit changes**.
7. Откройте **Actions → Publish Rift Cubes to GitHub Pages**. Дождитесь зелёной отметки у обеих задач: `build` и `deploy`.
8. Откройте **Settings → Pages**. Там будет настоящая опубликованная ссылка. Обычно она имеет вид `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.
9. Откройте ссылку в приватной вкладке браузера на телефоне. Игра должна открываться без входа в GitHub. Эту ссылку можно отправлять любому человеку.

Если загрузили файлы до включения Pages и первое выполнение завершилось ошибкой, включите Pages согласно шагу 3, затем в Actions выберите **Re-run all jobs**. Вручную запустить повторную публикацию также можно через **Run workflow**.

Каждое следующее изменение в `main` автоматически пересоберёт и обновит игру. Не включайте публикацию «из ветки» вместо GitHub Actions: исходный `index.html` требует сборки Vite.

### Через Git на компьютере

Создайте пустой Public-репозиторий на GitHub. В распакованной папке проекта выполните, заменив адрес на адрес своего репозитория:

```sh
git init -b main
git add .
git commit -m "Publish Rift Cubes 30-island edition"
git remote add origin https://github.com/ВАШ-ЛОГИН/ИМЯ-РЕПОЗИТОРИЯ.git
git push -u origin main
```

Затем включите **Settings → Pages → Source → GitHub Actions**, как описано выше. Если Actions уже завершился ошибкой до включения Pages, перезапустите выполнение. Настройка рассчитана на ветку `main`; при другом названии измените `branches` в `pages.yml`.

### Что загружать

В архив исходников входят все необходимые исходные файлы, локальные шрифты, тесты и workflow. В нём нет `node_modules`, истории Git, привязки к исходному Sites-проекту и секретов. Локальные файлы установки `node_modules` и папку сборки `dist` добавлять в репозиторий не нужно: Actions создаст сборку самостоятельно.

## 2. Netlify: публикация готовой сборки без Git и команд

1. Скачайте **архив готового сайта**, а не архив исходников.
2. Распакуйте его. Внутри будет папка `rift-cubes-public`, в которой находятся `index.html`, `assets` и `fonts`.
3. Войдите в Netlify и откройте ручное развёртывание: **Add new project / site → Deploy manually**. Название пункта может немного отличаться. Доступна и страница Netlify Drop: https://app.netlify.com/drop .
4. Перетащите **папку `rift-cubes-public` целиком** в область загрузки. Не выбирайте папку исходников: в готовом сайте уже нет зависимости от Vite во время работы.
5. Дождитесь публикации и скопируйте выданный адрес `…netlify.app`.
6. Проверьте ссылку в приватной вкладке. Настройки защиты паролем и ограничения доступа должны быть выключены, если хотите впускать всех.

Для обновления загрузите новую готовую сборку в тот же проект. Netlify требует учётную запись; бесплатный тариф имеет лимиты, которые зависят от действующих условий сервиса.

## 3. Дать всем доступ к текущему GPT Site

Текущая ссылка использует настройки доступа Sites. В момент подготовки инструкции она доступна только владельцу. Обновление игры само по себе аудиторию не расширяет.

Чтобы открыть именно её, откройте управление доступом / Share у сайта и выберите публичный доступ для всех, у кого есть ссылка (`Public`), затем сохраните изменение. Название и расположение пункта зависят от интерфейса. Для этого проекта публичный режим поддерживается. После изменения проверьте адрес в приватной вкладке без входа в аккаунт.

Переносить файлы для этого варианта не нужно. Публичный репозиторий на GitHub, напротив, сам по себе не меняет доступ к GPT Site.

## Телефоны и сохранения

- Джойстик слева — движение. Палец можно отклонять немного для медленного шага.
- Свайп по свободной части 3D-сцены — камера. Жест двумя пальцами по сцене меняет приближение.
- Справа — «Взять / Отпустить» и «Прыжок». При захвате отражателя появляется «Поворот».
- Для эхо доступны «Запись», «Повтор» и «Сброс»; клавиатура не нужна.
- «↶» отменяет перемещение, «↺» предлагает перезапуск, «✦» открывает подсказки.
- Работают вертикальная и горизонтальная ориентации. Для слабого устройства выберите **Пауза → Настройки → Графика → Экономно**.
- Полный экран предлагается в меню паузы, если браузер его поддерживает. На iPhone он может быть недоступен; обычный браузерный режим остаётся рабочим.
- Прогресс хранится в localStorage. После смены домена прежний прогресс автоматически не перенесётся. У каждого браузера и устройства своё сохранение.

Игра не является установленным приложением и не обещает работу без сети. Фактическая скорость зависит от телефона; для 3D нужен современный браузер с WebGL.

## Если вместо игры пустой экран

1. Для GitHub Pages убедитесь, что в Settings → Pages выбран **GitHub Actions**, а workflow завершился успешно.
2. Проверьте наличие `src`, `public/fonts`, `package-lock.json` и `.github/workflows/pages.yml` в репозитории.
3. Убедитесь, что запускается сборка из `dist`, а не исходники, открытые через `file://`.
4. После обновления перезагрузите страницу. При диагностике откройте её в новой приватной вкладке: это отделяет ошибки публикации от сохранённых настроек браузера.
