# Обновление «Кубов разлома» до 30 островов

Скачать только один `expansion.js` и оставить прежний движок недостаточно: новые задачи используют противоположные фазы, сохраняющиеся замки и расширенные индикаторы. Для этого подготовлен архив обновления с нужными файлами. Мобильная и компьютерная версии работают по одному адресу и используют одинаковые уровни.

## Если игра уже находится в вашем GitHub-репозитории

1. Скачайте `rift-cubes-30-update.zip` и распакуйте. Внутри лежат папки `src`, `tests`, `docs`, `.github` и файлы проекта, без дополнительной внешней папки.
2. Откройте ваш репозиторий → **Code → Add file → Upload files**.
3. Перетащите распакованные папки и файлы **в корень репозитория**, с заменой совпадающих файлов. Не загружайте ZIP как единственный файл. В корне должны находиться `index.html`, `package.json`, `package-lock.json`, `vite.config.js`, а рядом — `src` и `tests`.
4. Нажмите **Commit changes**, сохраните изменения в ветку **main**.
5. Проверьте **Settings → Pages → Source → GitHub Actions**.
6. Проверьте файл `.github/workflows/pages.yml`. Если скрытая папка не перенеслась, добавьте её через **Add file → Create new file**, введя этот полный путь и скопировав содержимое файла из архива.
7. Откройте **Actions → Publish Rift Cubes to GitHub Pages**. Дождитесь зелёных отметок `build` и `deploy`. Ссылка останется прежней; она указана в **Settings → Pages**.
8. Обновите страницу игры. При необходимости используйте **Ctrl+F5** на компьютере или перезагрузку страницы на телефоне.

Архив обновления рассчитан на существующий проект «Кубы разлома» с папкой `public/fonts`. Старые файлы шрифтов не меняются. Если структура вашего репозитория отличается или этих файлов нет, используйте полный архив исходников: он содержит всё, включая шрифты.

Сохраняются пройденные уровни, громкость, чувствительность и качество графики. У игрока, прошедшего прежний десятый остров, открывается одиннадцатый. Сохранение совместимо при обновлении **по тому же адресу**; другой домен или другой браузер хранит отдельный прогресс.

## Для нового репозитория

Скачайте `rift-cubes-30-source.zip`, распакуйте и загрузите **содержимое папки `rift-cubes`** в корень Public-репозитория. Затем выполните шаги 5–7 выше. Полная инструкция: [PUBLICATION.md](PUBLICATION.md).

## Если нужен готовый сайт без сборки

Скачайте `rift-cubes-30-public.zip`. В нём находится `rift-cubes-public/index.html` и готовые `assets`, `fonts`. Эту папку можно загрузить на статический хостинг, например Netlify Drop. Исходники и Node.js для посетителей не нужны.

Если хотите опубликовать готовую сборку через GitHub Pages без Actions, используйте отдельный репозиторий: положите **содержимое** `rift-cubes-public` в его корень, в **Settings → Pages** выберите **Deploy from a branch → main → /(root)**. После публикации ссылка появится там же. Для обновления заменяйте готовые файлы новой сборкой.

## Локальный запуск исходников

Установите Node.js 20.19+ или 22.12+. В папке проекта:

```sh
npm ci
npm run dev
```

Откройте http://localhost:5173. Для проверки и сборки:

```sh
npm test
npm run build
```

Не открывайте исходный HTML двойным щелчком: игре нужен локальный сервер или хостинг. Платных API и серверной части у игры нет.
