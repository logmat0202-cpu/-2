# Внешний пояс и созвездие

Первые десять островов знакомят с инструментами. Новые двадцать проверяют планирование, доступ к кубам и повторное использование ресурсов. У каждого острова есть три подсказки в игре: общий намёк, взаимодействие и конкретное решение.

| № | Остров | Пространственная задача |
|---|---|---|
| 11 | Один куб — два ключа | Сервисный замок сохраняет нажатие; единственный груз и проводники нужно провести через узкий общий проход. |
| 12 | Двойной изгиб | Связанная пара освобождает коридор, два зеркала ведут луч вокруг угла и обратно. |
| 13 | Длинный путь домой | Перевозка энергии по южному обходу между берегами; возвращение к исходному порталу по северной перемычке. |
| 14 | Чужая память | Эхо остаётся в первой комнате и управляет вашим проходом и фазой оптики во второй. |
| 15 | Разборный мост | Фаза помогает доставить зеркало, но блокирует свет. После доставки нужно разрушить старый мост и получить другой маршрут. |
| 16 | Ключ на другом берегу | Груз держит транспортный мост, удалённая пара запускает два ключа, энергия включает верхний подъёмник. |
| 17 | Галерея затмений | Одно зеркало последовательно обслуживает два приёмника; первый открывает путь ко второму. |
| 18 | Две пары — одна проходная | Внутренняя пара уступает исходные места внешней. Парковка открывает проходы; затем обе пары расходятся к своим целям. |
| 19 | Поднятая оптика | Энергия внизу, зеркала и ступенька наверху. Требуется подняться, обойти приёмник грузом и прыгнуть на ещё более высокий мост. |
| 20 | След сквозь камень | Два прохода вокруг центрального провала обслуживает эхо. Преждевременная установка пары перекрывает дорогу доставки. |
| 21 | Энергетическое дерево | Три проводника образуют общий узел двух ветвей. Пару нужно убрать с будущей цепи прежде, чем замкнуть её. |
| 22 | Заряд с собой | Два проводника многократно используются в трёх станциях, проходя разные узкие проёмы. Последняя цепь работает вместе с эхо и зеркалом. |
| 23 | Третий поворот | Три зеркала задают маршрут восток → север → восток → север; две фазовые стены управляются разными сторонами пары. |
| 24 | Без лишнего веса | На исходном острове нет массы: проводник временно держит мост, пока робот спасает массу и зеркало с другого берега. |
| 25 | Световая развилка | Связанные кубы служат парными заслонками встречных лучей. Одинаковые повороты зеркал дают противоположные выходы, эхо синхронизирует питание. |
| 26 | Часовая спираль | Длинная запись открывает два разных прохода: пара идёт одним, зеркало возвращается другим, робот снова идёт к северному порталу. |
| 27 | Остров наоборот | Два моста работают в противоположных фазах. Эхо даёт окно для доставки, а свет срабатывает после смены состояния. |
| 28 | Дальний отклик | Пара управляет удалёнными стенами. Два проводника забираются из первой цепи в верхнюю, где эхо поддерживает общую синхронизацию. |
| 29 | Три маршрута робота | Цепь, зеркало и пара используются повторно. Пара отправляется в противоположные концы длинного острова; робот возвращается за инструментами. |
| 30 | Созвездие разлома | Большой остров с западным, восточным и северным крыльями: перенос одного груза и двух проводников, составная оптика, шесть одновременных условий и часы эхо. |

Бирюзовые мосты и стены работают в обычной фазе, янтарные — в противоположной. Замки с подписью «сохранён» остаются открыты после снятия куба. Постоянный заряд помогает использовать одни инструменты в нескольких зонах. Отмена возвращает также состояние замков.

В паузе доступна карта с координатами, текущими кубами, фазовыми мостами и лучами. На компьютере её открывает M. На телефоне: Пауза → Карта острова. Цифры в конкретных подсказках относятся к этой карте, север показан сверху.

Для проверки разработчика: `solution` у каждого уровня содержит выполнимые перемещения и операции записи/поворота. `npm test` проверяет их логику, действительное перетаскивание через `Player.update`, доступ к кубам и путь к каждому порталу с прыжками и подъёмниками. Браузерные сценарии отдельно проверяют завершение всех тридцати островов, сохранение, новый финал и сенсорный интерфейс. Проверка не утверждает, что решение единственное.
